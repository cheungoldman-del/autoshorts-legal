AutoShorts

個人用自動短片生成工具（Hermes agent）

這個應用程式是什麼

AutoShorts 是一個個人自用的內容自動化工具。它每日在擁有者本人的電腦上 本機執行，用本地 AI 模型生成冷知識短片的文案、配音、字幕與剪輯，然後透過 YouTube Data API 把完成品上傳到擁有者本人自己的 YouTube 頻道。

本應用程式不對外提供服務，沒有其他使用者，也不收集任何第三方的資料。 所有運算與檔案儲存都在擁有者本人的裝置上完成。

使用的 Google 服務

  • YouTube Data API v3 — 僅用於把影片上傳到擁有者本人的頻道。 使用的授權範圍（scope）為 youtube.upload、 youtube.force-ssl 及 youtube.readonly。
  • Google Drive API — 僅用於把較大的成品檔案暫存到擁有者本人的雲端硬碟， 方便跨裝置取用。

YouTube API Services 聲明

本應用程式使用 YouTube API Services。使用本應用程式即表示您同意 YouTube 服務條款。 關於 Google 如何處理資料，請參閱 Google 隱私權政策。

您可以隨時前往 Google 帳戶權限頁面撤銷本應用程式的存取權。

授權資料的處理

OAuth 權杖只儲存在擁有者本人的電腦上（權限 600，只有該使用者可讀）， 不會上傳到任何伺服器，也不會分享給第三方。本應用程式沒有後端伺服器。
